# Simplification pass: orpheusdl-amazonmusic

**Baseline:** 6,426 LOC — `azapi.py` 2,168 / `interface.py` 4,064 / `models.py` 194.
**Target:** ~28-32% reduction (~1,800-2,000 lines) with zero functional change toward orpheusdl core. User decisions: **fix the 2 copy-paste bugs**; **thorough depth**.

## Hard preservation guarantees (never touched)

- **Framework hooks, exact signatures:** `module_information`, `validate_amazonmusic_setup`, and on `ModuleInterface`: `__init__`, `custom_url_parse`, `get_track_info`, `get_track_download`, `get_preview_audio_path`, `get_album_info`, `get_playlist_info`, `get_artist_info`, `get_track_credits`, `get_track_cover`, `get_track_lyrics`, `search`, `artist_album_display_meta`, `has_cached_credentials`. `login_behaviour=ManualEnum.manual` semantics stay (no `login()` exists; lazy login in `__init__` stays).
- **Credential cache compat:** keep ALL dataclass fields in `AmazonMusicMobileAPICredentials`/`AmazonMusicDevice` (incl. write-only `store_authentication_cookie`, `device_name`, `device_type`) — `is_dict_of_instance` requires the full field set against existing `loginstorage.bin`. Keep `from_dict` legacy-key migration (`web_client_config`/`tld` pops).
- **Caching semantics:** keep `lru_cache` on `get_metadata`, `get_account_status`, `select_session`.
- **Behavior quirks to preserve:** `_search` dual return shape (dict when `asins` given, list otherwise); `get_track_lyrics` hardcoded region→tld map (differs from `AmazonRegion.domain_tld` for JP/EU); `_wait_for_response` retry count/sleep; ThreadPoolExecutor manifest batching (4 workers, chunks of 10); `tracks_to_quality_map` None-key filtering; request header variants currently accepted by the server (normalize to one form).
